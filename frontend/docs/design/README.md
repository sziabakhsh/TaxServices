# Amazing Accountant and Tax Services — Visual Direction

The homepage mockup in this folder is the visual reference for the public website.

Core direction:
- Clean, premium, trustworthy accounting/financial aesthetic
- White space with the logo's blue palette
- Dark navy typography + bright blue actions
- Soft light-blue backgrounds and subtle shadows
- Rounded cards with restrained borders
- Geometric accents inspired by the logo
- Clear hierarchy and low-friction calls to action

The mockup is a design reference, not a production screenshot. The implementation should reproduce its UX, hierarchy, spacing, visual rhythm, and content intent while using real site components and real business content.
